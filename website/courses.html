4-Week Curriculum

A structured path from Linux basics to containerized deployments.

Week 1

Linux Fundamentals

Build a strong command-line foundation, the base of every DevOps role.

  • File system, permissions and users/groups
  • Essential commands, package management and processes
  • Shell scripting and automation with cron
  • SSH, networking basics and log analysis
Week 2

Cloud Computing

Understand cloud models and deploy real infrastructure.

  • IaaS, PaaS, SaaS and shared responsibility
  • Virtual machines, storage, VPC and security groups
  • IAM, load balancing and monitoring
  • Hosting a web application on a cloud server
Week 3

Git & CI/CD

Collaborate on code and automate builds, tests and releases.

  • Git workflows: branching, merging, pull requests
  • GitHub / GitLab repositories and collaboration
  • Designing CI/CD pipelines (build, test, deploy)
  • Automating deployments with GitHub Actions / Jenkins
Week 4

Docker & Containers

Package and ship applications consistently anywhere.

  • Images, containers, volumes and networks
  • Writing efficient Dockerfiles
  • Multi-container apps with Docker Compose
  • Capstone: containerized web app with a database
